# 🎵 Lumi Music

> **"Feel Every Word, Hear Every Beat."**  
> **Developed by Kaif** • Instagram: [@Kaif_7.0x](https://instagram.com/Kaif_7.0x)

**Lumi Music** is an open-source, full-featured native Android music client with official **Spotify Web Player & GraphQL API integration** and **YouTube Music ad-free streaming**.

---

## ✨ Features

- **🎧 The Full Spotify Experience (Ad-Free):**
  - Sign in with your standard free Spotify account.
  - Browse your exact official Spotify Home feed, Made For You, Daily Mixes, Discover Weekly, and Top Charts.
  - Full catalog search: Every track, artist, album, and playlist worldwide.
  - Your personal Library with liked songs, folders, and collaborative playlists.
- **🎤 Real-Time Synced Lyrics & Genius Meanings:**
  - Word-by-word synchronized karaoke-style lyrics.
  - Built-in song meanings & annotations from Genius.
- **⚡ Hybrid Streaming & Offline Downloads:**
  - Ad-free streaming powered by the official Spotify Web Player DRM bridge and YouTube Music extensions.
  - Offline encrypted downloads for songs, albums, and playlists.
- **📱 Native Jetpack Compose UI:**
  - Modern AMOLED Dark theme with Immersive & Classic player modes.
  - Spotify Connect, Bluetooth device management, and lock screen media notification controls.

---

## 🛠️ Tech Stack & Architecture

- **UI:** Jetpack Compose + Material 3 (AMOLED Black theme)
- **APIs:** Spotify GraphQL API + Web Player Bridge (`:api-spotify`, `:api-web`)
- **Extensions:** YouTube Music audio resolution (`:api-ytmusic`, `:extensions`)
- **Engine:** AndroidX Media3 (ExoPlayer) + DrmPlayer (`:engine`, `:engine-android`)
- **Architecture:** Clean modular multi-project architecture with Kotlin 2.4 & Android Gradle Plugin
